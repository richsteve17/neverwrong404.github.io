# 👁️ neverwrong404.github.io

**Anti-Platform Personal Site, PWA & Creative Suite**

Personal website, creative hub, and standalone PWA built with a raw glitch aesthetic, hidden links, and integrated mini-tools.

---

## 🛠️ Built-in Apps & Tools
- **Personal Web Hub**: Glitch aesthetic terminal interface with project directories and links.
- **Drum Pad Coach (`/drumpad`)**: Vertical 2x4 DJ pad interface with visual song guides and interactive beat practice.
- **Gmail Sorter (`/GmailSorter`)**: AI email triage utility designed for fast mobile categorization.
- **PWA Capabilities**: Fully installable offline-capable web application.
